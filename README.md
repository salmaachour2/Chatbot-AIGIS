# Chatbot AIGIS

**AIGIS** est un chatbot intelligent dédié à l'analyse et à la gestion des structures et bâtiments.  
Il permet de poser des questions techniques et d’obtenir des réponses précises grâce à l'intelligence artificielle.

---

## Technologies utilisées

- **Python 3**
- **Streamlit** pour l'interface utilisateur
- **OpenRouter API** pour l'IA
- **SQLite** pour la base de données
- **PIL / Pillow** pour le traitement d'images
- **Git & GitHub** pour le contrôle de version

---

## Fonctionnalités principales

- Ajouter, gérer et analyser des conversations
- Poser des questions techniques sur les structures et bâtiments
- Analyser des images liées aux projets
- Organiser les connaissances dans des bases dédiées
- Interface simple et interactive avec Streamlit
